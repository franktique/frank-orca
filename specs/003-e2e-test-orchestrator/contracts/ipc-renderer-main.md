# Contract: Renderer ↔ Main IPC (`window.api.testRun`)

- **Preload**: `src/preload/api/test-run-api.ts` (+ bridge).
- **Handlers**: `src/main/ipc/test-orchestrator/test-run-ipc.ts`.

These follow the feature 001 conventions:

- Main validates every payload with zod.
- Every channel takes `worktreeId` and fails with `{ ok: false, code: 'not-local' }` for non-local execution hosts. This uses the existing `assertLocal`.
- Errors come back as `{ ok: false, code, message }` and successes as `{ ok: true, … }`.

Error codes are `not-local`, `not-found`, `invalid-test-map`, `busy` (a run of this plan is active, FR-020), `host-not-allowed`, `host-unconfirmed`, `missing-inputs`, `connection-failed`, `console-not-found`, `no-pause`, and `pause-mismatch`.

No RPC method or CLI command is added (FR-028). Paired clients and agents cannot reach any of this.

| `testRun:getTestMap`                               | `{ worktreeId, collectionId }`                                                                                   | `TestMap \| null`, with `link` states refreshed against the current collection (`broken` for deleted requests)                                                                                                                                                                                                                                                                                 |
| `testRun:saveQueries`                              | `{ worktreeId, collectionId, requestId, before: VerificationQuery[], after: VerificationQuery[], baseLoadedAt }` | Creates a test-map entry if the request has none. Returns `conflict` if the map was replaced meanwhile                                                                                                                                                                                                                                                                                         |
| `testRun:pickExportFile` / `testRun:exportTestMap` | `{ worktreeId, collectionId, filePath }`                                                                         | Writes the `orcaTestMap: 1` file with `path` references                                                                                                                                                                                                                                                                                                                                        |
| `testRun:removeTestMap`                            | `{ worktreeId, collectionId }`                                                                                   | After the user confirms                                                                                                                                                                                                                                                                                                                                                                        |

## Run

| Channel                  | Params                                                                                                                                                                                                                                                                                     | Returns / notes                                                                                                                                                                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `testRun:start`          | `{ worktreeId, collectionId, environmentId, kind: 'full' \| 'cleanup-only', inputs: Record<string,string>, remember: { inputs: boolean; secrets: boolean }, database: DatabaseModeChoice \| null, browserPageId?, confirmedHosts: string[], approvedDataChanges: string[] /* stepIds */ }` | `{ runId }`. Main checks the hosts again (`host-not-allowed` / `host-unconfirmed`), the inputs (`missing-inputs`), and the database mode before anything is sent. Secret inputs come over IPC in plain text once, as in feature 001's environment save, and are sealed before they are written |
| `testRun:stop`           | `{ worktreeId, runId }`                                                                                                                                                                                                                                                                    | Moves the run to `stopping`. The run then raises the cleanup prompt as a pause                                                                                                                                                                                                                 |
| `testRun:answerPause`    | `{ worktreeId, runId, pauseId, answer: PauseAnswer }`                                                                                                                                                                                                                                      | `PauseAnswer` is a discriminated union for each `PauseRequest.kind` (data-model.md), plus `{ kind: 'stopping', choice: 'run-cleanup' \| 'keep-data' }`. Returns `no-pause` / `pause-mismatch` for stale answers                                                                                |
| `testRun:getRun`         | `{ worktreeId, collectionId }`                                                                                                                                                                                                                                                             | The live `TestRun` if one is active, otherwise the latest stored one, otherwise `null`                                                                                                                                                                                                         |
| `testRun:getStepDetail`  | `{ worktreeId, collectionId, runId, stepIndex }`                                                                                                                                                                                                                                           | `StepResult` with full request and response detail (for `RunResultDetail`)                                                                                                                                                                                                                     |
| `testRun:forgetCaptures` | `{ worktreeId, collectionId }`                                                                                                                                                                                                                                                             | After the user confirms. Clears the ledger                                                                                                                                                                                                                                                     |

## Events (main → renderer)

| Channel                  | Payload                                                                                                                                                                    |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `testRun:changed`        | `{ worktreeId, collectionId, run: TestRunSummary }`: state, current step, finished-step results, elapsed and paused time. Throttled to about 10/s, plus every state change |
| `testRun:paused`         | `{ worktreeId, collectionId, runId, pause: PauseRequest & { pauseId } }`                                                                                                   |
| `testRun:finished`       | `{ worktreeId, collectionId, run: TestRunSummary, evidence: { reportPath, folder, ignoredByGit } }`                                                                        |
| `testRun:testMapChanged` | `{ worktreeId, collectionId }`: after load, save, remove, or re-match on re-import                                                                                         |

## Evidence snapshot renderer (main ↔ hidden window, internal)

These channels are internal to the hidden `evidence-snapshot.html` window (R6). The main renderer never sees them.

| Channel                    | Direction       | Payload                                                                                                                                    |
| -------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `evidenceSnapshot:render`  | main → snapshot | `{ token, card: { kind: 'request', resolvedRequest, outcome, title } \| { kind: 'query', sql, result \| error, title } }` (already masked) |
| `evidenceSnapshot:painted` | snapshot → main | `{ token, width, height }`. Sent after two animation frames. Main then sizes the window to the card and calls `capturePage()`              |

The snapshot window's preload exposes only these two channels.
