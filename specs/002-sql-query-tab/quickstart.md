# Quickstart & Validation: SQL Tab

How to prove the feature works end to end. Contracts: [ipc-renderer-main](./contracts/ipc-renderer-main.md), [cli-rpc](./contracts/cli-rpc.md), [storage-format](./contracts/storage-format.md). Entities: [data-model.md](./data-model.md).

## Prerequisites

- Node 24, `pnpm install` (adds `pg`, `pg-cursor`).
- A local PostgreSQL 16 in Docker:

  ```bash
  docker run -d --name orca-sql-test -e POSTGRES_PASSWORD=orca-test-pw -p 55432:5432 postgres:16
  export ORCA_TEST_PG_URL=postgres://postgres:orca-test-pw@localhost:55432/postgres
  ```

- Seed fixture (committed as `src/main/sql-client/test-support/seed.sql`): schema `"CaseManagement"` with table `"SurgicalCase"` (uuid PK, text, numeric(30,10), jsonb, timestamptz, int[], bytea, interval, nullable columns), a view, a 5 000-row table `wide_rows` with 40 columns, and a table with ~60 MB of text for the size limit (in a separate `seed-big-text.sql`, loaded only by the suites that test the size limit).
- For the read-only agent check, a second hostname pointing at the same container that is **not** loopback (e.g. the machine's LAN IP).

## Automated checks

```bash
pnpm tc
pnpm test src/shared/sql-client src/main/sql-client src/renderer/src/components/sql-client
ORCA_TEST_PG_URL=… pnpm test src/main/sql-client --testNamePattern sql-integration
pnpm run check:code-quality:changed
oxlint
pnpm verify:bundled-skill-guides
ORCA_BACKGROUND_LAUNCH=1 pnpm test:e2e tests/e2e/sql-client   # hidden window, CDP screenshots
```

Expected: all green. Integration tests are skipped (not failed) when `ORCA_TEST_PG_URL` is unset; CI provides it with a `postgres:16` service.
