# Contract: Renderer ↔ Main IPC (`window.api.apiClient`)

Preload: `src/preload/api/api-client-api.ts` (+ bridge), handlers in `src/main/ipc/api-client/`. Every payload is validated with zod in main. All methods take `worktreeId` and fail with `{ code: 'not-local' }` for non-local execution hosts (FR-001a).

Errors are returned as `{ ok: false, code, message }`; success as `{ ok: true, ... }`. Codes: `not-local`, `not-found`, `conflict` (stale `revision`), `invalid-import`, `busy` (a run is already active for that scope), `duplicate-name` (import name clash). `getSnapshot`, `saveEnvironment`, and `importFile` return an optional `secretProtection: { level: 'memory-only' | 'weak', message }` (the `describeProtectionGap()` text): `memory-only` = secrets kept in memory and not written; `weak` = written with Linux `basic_text`. These are successes, not errors.

The SSL verification switch is app-wide and lives in Orca's existing settings (`GlobalSettings.apiClientSslVerification`), so it has no `apiClient:*` channel.

## Queries

| Channel                     | Params                      | Returns                                                                                                                                                                 |
| --------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiClient:getSnapshot`     | `{ worktreeId }`            | `WorktreeApiData` with collection trees and environments (secret values decrypted only when `revealSecrets: true` is passed by the environment editor's reveal action). |
| `apiClient:getLatestResult` | `{ worktreeId, requestId }` | `LatestResult \| null`                                                                                                                                                  |
| `apiClient:getLatestRun`    | `{ worktreeId, scopeId }`   | `Run \| null`                                                                                                                                                           |
| `apiClient:getConsole`      | `{ worktreeId }`            | `ConsoleEntry[]` (≤ 500)                                                                                                                                                |

## Mutations (UI only — never exposed over RPC/CLI, FR-035)

| Channel                          | Params                                                                               | Notes                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiClient:importFile`           | `{ worktreeId, filePath, onDuplicate?: 'replace' \| 'keep-both' }`                   | Detects collection vs environment. Returns `{ kind, id, warnings[] }`, or `{ ok:false, code:'duplicate-name', existingId }` when `onDuplicate` is omitted and a name clashes. Writes nothing on failure (acceptance 1.4).                                                                                                                                            |
| `apiClient:export`               | `{ worktreeId, kind: 'collection'\|'environment', id, filePath }`                    | Environment export writes secrets as plain values; the renderer shows a warning dialog before calling.                                                                                                                                                                                                                                                               |
| `apiClient:saveRequest`          | `{ worktreeId, collectionId, request, baseRevision }`                                |                                                                                                                                                                                                                                                                                                                                                                      |
| `apiClient:saveEnvironment`      | `{ worktreeId, environment, baseRevision }`                                          | A secret's value is sent only if the user revealed or changed it. A secret sent as `{ key, enabled, type: 'secret', unchanged: true }` (no `value`) keeps its stored cipher. Changed or new secret values arrive in plain text over IPC and are encrypted before writing. An `unchanged` secret with no stored cipher (renamed or new) is rejected with `not-found`. |
| `apiClient:treeOp`               | `{ worktreeId, op: 'create'\|'rename'\|'duplicate'\|'move'\|'delete', target, ... }` | Collections, folders, requests (FR-005).                                                                                                                                                                                                                                                                                                                             |
| `apiClient:envOp`                | `{ worktreeId, op: 'create'\|'rename'\|'duplicate'\|'delete', ... }`                 | FR-008.                                                                                                                                                                                                                                                                                                                                                              |
| `apiClient:setActiveEnvironment` | `{ worktreeId, environmentId \| null }`                                              | FR-010.                                                                                                                                                                                                                                                                                                                                                              |
| `apiClient:clearConsole`         | `{ worktreeId }`                                                                     |                                                                                                                                                                                                                                                                                                                                                                      |
| `apiClient:clearRun`             | `{ worktreeId, scopeId }`                                                            | FR-026. Deletes `runs/<scopeId>.json`.                                                                                                                                                                                                                                                                                                                               |

## Execution

| Channel              | Params                                          | Returns                                                                                                        |
| -------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `apiClient:send`     | `{ worktreeId, requestId, draft?: Request }`    | `{ executionId }`; result arrives via `apiClient:executionFinished`. `draft` lets the user send unsaved edits. |
| `apiClient:cancel`   | `{ worktreeId, executionId }`                   | FR-017.                                                                                                        |
| `apiClient:startRun` | `{ worktreeId, scope, environmentId, options }` | `{ runId }`                                                                                                    |
| `apiClient:stopRun`  | `{ worktreeId, runId }`                         | FR-024.                                                                                                        |

## Events (main → renderer)

| Channel                       | Payload                                                                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiClient:changed`           | `{ worktreeId, revision, kind: 'collection'\|'environment'\|'active-environment', id? }` — renderers refetch what they display.                     |
| `apiClient:executionFinished` | `{ worktreeId, executionId, requestId, result: LatestResult }`                                                                                      |
| `apiClient:consoleAppended`   | `{ worktreeId, entry: ConsoleEntry }`                                                                                                               |
| `apiClient:runProgress`       | `{ worktreeId, runId, result: RunRequestResult, totals }`                                                                                           |
| `apiClient:runFinished`       | `{ worktreeId, run: Run }`                                                                                                                          |
| `apiClient:show`              | `{ worktreeId, requestId }` — from CLI/agent `api.show` (FR-037); renderer ensures an API Client tab, selects the request, shows its latest result. |

Size limits: response bodies in events are capped at 10 MB with `truncated: true`; console payloads hold body previews ≤ 256 KB with a "load full body" call to `getLatestResult`.
